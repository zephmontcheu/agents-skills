# Workflow: graphify

Follow the `graphify` skill to run the full pipeline. If no path argument is given, use `.` (current directory).

If the skill is not installed: `uv tool install graphifyy` (or `pipx install graphifyy`), then `graphify install` to add the skill to your agent.
